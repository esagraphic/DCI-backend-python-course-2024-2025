# Python Calendar

## Task 1 

Write a program that takes a date as input and checks if that date falls on a weekend (Saturday or Sunday).

### Examples:

```
2024-07-23 is a weekend: False
2024-07-27 is a weekend: True
```

### Task 2

Write a program that takes a year as input and returns the first and last day of each month in that year.

### Examples:

```
January: First day - 2024-01-01, Last day - 2024-01-31
February: First day - 2024-02-01, Last day - 2024-02-29
...
...
...
December: First day - 2024-12-01, Last day - 2024-12-31
```

### Task 3

Write a program that takes two years as input and returns the number of leap years between them, inclusive.

### Examples:

```
Leap years between 2000 and 2100: 25
```
